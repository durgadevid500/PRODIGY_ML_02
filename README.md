# PRODIGY_ML_02
# Customer Segmentation using K-Means

## Project Overview
This project implements customer segmentation using the K-Means Clustering algorithm. It groups mall customers based on their annual income and spending score to identify different customer segments.

## Internship
Prodigy InfoTech – Machine Learning Internship

## Task
Task 02 – Customer Segmentation using K-Means

## Dataset
Mall Customers Dataset

- Total Customers: 200
- Total Features: 5
- Missing Values: 0

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithm
K-Means Clustering (Unsupervised Learning)

## Project Workflow
1. Dataset loading
2. Data cleaning
3. Exploratory Data Analysis (EDA)
4. Feature selection
5. Feature scaling using StandardScaler
6. Optimal cluster selection using Elbow Method
7. K-Means clustering
8. Model evaluation using Silhouette Score
9. Customer cluster visualization
10. Cluster analysis and CSV export

## Features Used for Clustering
- Annual Income (k$)
- Spending Score (1-100)

## Model Results
- Number of Clusters: 5
- Silhouette Score: 0.5547
- Total Customers Segmented: 200

## Cluster Analysis

| Cluster | Customer Segment |
|---|---|
| 0 | Average Income, Average Spending |
| 1 | High Income, High Spending |
| 2 | Low Income, High Spending |
| 3 | High Income, Low Spending |
| 4 | Low Income, Low Spending |

The K-Means clustering algorithm successfully segmented 200 mall customers into five groups based on annual income and spending score. This analysis can help businesses understand customer behaviour and develop targeted marketing strategies.
